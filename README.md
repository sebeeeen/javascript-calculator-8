## 구현할 기능 목록
### 입력 처리
- [x] 사용자로부터 문자열 입력받기 (Console.readLineAsync 사용)
- [x] 빈 문자열 입력 시 0 반환
### 문자열 파싱
- [x] 커스텀 구분자 확인 ("//구분자\n" 패턴)
- [x] 커스텀 구분자 추출
- [x] 기본 구분자(쉼표, 콜론)와 커스텀 구분자로 문자열 분리
### 숫자 계산
- [x] 분리된 문자열을 숫자로 변환
- [x] 음수 입력 시 에러 발생
- [x] 숫자가 아닌 값 입력 시 에러 처리
- [x] 모든 숫자의 합 계산
### 출력
- [x] 계산 결과 출력 (형식: "결과 : {숫자}")
- [x] 에러 발생 시 "[ERROR]"로 시작하는 메시지와 함께 Error 발생

## 구현 내용

### 주요 기능
- **빈 문자열 처리**: 빈 문자열 입력 시 0을 반환
- **기본 구분자**: 쉼표(,)와 콜론(:)을 구분자로 사용
- **커스텀 구분자**: `//구분자\n` 형식으로 사용자 정의 구분자 지정 가능
  - 예: `//;\n1;2;3` → 세미콜론을 구분자로 사용
- **입력 검증**: 음수 및 숫자가 아닌 값에 대한 예외 처리

### 코드 구조
```
App
├── run(): 프로그램 실행 진입점
├── calculate(input): 전체 계산 로직 수행
├── parseInput(input): 커스텀 구분자 파싱 및 숫자 문자열 추출
├── parseNumbers(numbers, delimiter): 문자열을 숫자 배열로 변환
├── validateNumber(num): 숫자 유효성 검증
└── escapeRegExp(string): 정규식 특수문자 이스케이프
```

### 구현 과정
1. **입력 처리 및 기본 구조** (빈 문자열 처리)
2. **기본 구분자 처리** (쉼표, 콜론)
3. **커스텀 구분자 파싱** (`//`와 `\n` 사이 문자 추출)
4. **예외 처리** (음수, 잘못된 입력)
5. **코드 리팩토링** (함수 분리, Airbnb 스타일 가이드 적용)

### 예외 처리
- **음수 입력**: `[ERROR] 음수는 입력할 수 없습니다.`
- **숫자가 아닌 값**: `[ERROR] 숫자가 아닌 값이 포함되어 있습니다.`

```

```
