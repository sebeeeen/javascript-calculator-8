## 구현할 기능 목록

### 입력 처리
- [ ] 사용자로부터 문자열 입력받기 (Console.readLineAsync 사용)
- [ ] 빈 문자열 입력 시 0 반환

### 문자열 파싱
- [ ] 커스텀 구분자 확인 ("//구분자\n" 패턴)
- [ ] 커스텀 구분자 추출
- [ ] 기본 구분자(쉼표, 콜론)와 커스텀 구분자로 문자열 분리

### 숫자 계산
- [ ] 분리된 문자열을 숫자로 변환
- [ ] 음수 입력 시 에러 발생
- [ ] 숫자가 아닌 값 입력 시 에러 처리
- [ ] 모든 숫자의 합 계산

### 출력
- [ ] 계산 결과 출력 (형식: "결과 : {숫자}")
- [ ] 에러 발생 시 "[ERROR]"로 시작하는 메시지와 함께 Error 발생
